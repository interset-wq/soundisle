# Android 验收清单

产物：`app/build/app/outputs/flutter-apk/app-release.apk`（arm64-v8a，稳定 release 签名）。

完整测试用例、排障决策树与日志采集方法见 [`testing-guide.md`](testing-guide.md)。
遇到问题时可运行 `scripts/collect_android_diagnostics.sh` 一键取证。

## 第二版（1.0.1）重点回归

| 编号    | 问题                         | 本版改动                                                                 | 验收方式                                                                       |
| ------- | ---------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| BUG-001 | 播放页底部约 1/5 留白        | 播放页内容改为填满整屏并均匀分布，短屏仍可滚动                           | 打开播放页，封面/标题/进度/控制区应从上到下铺满，底部无大块空白                |
| BUG-002 | 下载后找不到文件             | 下载完成后自动复制到系统 `Music/声屿/`（MediaStore），下载页显示保存位置 | 下载一首歌，等状态变“已完成”；用文件管理器查看 `Music/声屿`，或用其他音乐 App 扫描 |
| BUG-003 | 首页部分歌曲无法播放         | 原音源失败时自动搜索其他平台同名歌曲并播放，播放页顶部标注“已自动切换”   | 点开之前失败的歌曲，应能播放或给出明确的“其他音源也不可用”提示                 |
| BUG-004 | 收藏后出现黑色矩形           | 统一 SnackBar 文字为白色，动作色/圆角/内边距一并调整                     | 在迷你播放器点红心，提示应为深色圆角条 + 白色文字，清晰可读                    |
| BUG-005 | 启动器仍是默认 Flutter 图标  | 图标脚本修正缩放，全套图标重新生成（含自适应前景）                       | 安装后在桌面/最近任务中应看到「声屿」海岛声波图标，图案不再缩成小点             |

> 说明：Android 9 及以下导出到公共目录需要存储权限；Android 10+ 通过 MediaStore 写入，无需额外授权。
> 若个别歌曲在所有音源都无版权，仍会播放失败，但错误提示会说明已尝试换源。

## 安装

```bash
adb devices
adb install -r app/build/app/outputs/flutter-apk/app-release.apk
```

首次打开会请求通知权限（后台播放需要）。若系统拦截「安装未知来源」，在
「设置 → 应用 → 声屿 → 允许安装」中放行。

## 已知限制

- 1.0.2 起使用稳定 release 签名；1.0.1 及更早版本需卸载后才能升级
- 仅构建 arm64-v8a，不支持 32 位设备与 x86_64 模拟器
- 音源可用性取决于上游 `music-lib` 与平台 Cookie，个别歌曲可能无版权或 404；
  本版会自动换源重试，但仍存在全部音源都不可用的情况
- 首次播放需联网；已下载歌曲可离线
- 未集成 AAR 时应用仍可安装，但启动会提示核心缺失
- 系统 `Music/声屿` 里的文件是下载完成后的副本；应用内删除本地歌曲不会自动删除该副本

## 排障

```bash
adb logcat -s flutter:V GoLog:V
```

- 提示「音乐核心未集成」：重新执行 `./scripts/build_mobile_core.sh android`
  后重新打包
- 白屏 / 启动超时：确认 `MainActivity` 继承 `AudioServiceActivity`
- 播放无声音：检查通知权限与 `FOREGROUND_SERVICE_MEDIA_PLAYBACK`
- 下载完成但文件管理器看不到：确认系统为 Android 10+，并查看下载页的保存位置提示；
  低版本系统需要授予存储权限
- 提示“已自动切换到 xx 音源”但仍失败：该歌曲在各平台均无可用音频，可尝试登录对应平台或更换搜索源
