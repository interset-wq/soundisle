# 声屿 Android 测试与排障手册

适用版本：**1.0.5（v3 验收包，Release tag `v1.0.5-android.*`）**
适用平台：Android 手机（arm64-v8a）

> 本手册按「安装 → 冒烟 → 分模块回归 → 排障 → 取证 → 反馈」顺序编写。
> 用例编号可直接写进反馈，例如「P-03 失败」。

---

## 0. 先看这里：30 秒快速判断

安装新版后，先按顺序做这 5 件事。任意一项失败，先看第 6 节对应排障。

| #   | 操作                       | 正常表现                                       |
| --- | -------------------------- | ---------------------------------------------- |
| 0-1 | 冷启动 App                 | 显示「声屿 / 正在启动音乐核心…」，随后进入首页 |
| 0-2 | 首页出现推荐/热门/排行榜   | 有封面、有歌曲，不是整页「加载失败」           |
| 0-3 | 点一首热门歌曲             | 开始播放，底部出现迷你播放器                   |
| 0-4 | 点迷你播放器               | 进入播放页，封面/标题/进度/控制按钮完整        |
| 0-5 | 点歌曲右侧「⋯」→ 下载到本地 | 提示已加入队列；音乐库→下载可见任务和保存位置  |

以上都正常，再继续做完整回归；不正常时不要反复重装，先按第 6 节收集证据。

## 1. 安装与版本确认

### 1.1 安装包信息

| 项目         | 值                                                        |
| ------------ | --------------------------------------------------------- |
| 应用名       | 声屿                                                      |
| 包名         | `app.soundisle.music`                                     |
| APK 文件名   | `soundisle-android.apk`                                   |
| 支持架构     | `arm64-v8a`（**不支持 32 位设备与 x86_64 模拟器**）       |
| 签名         | 稳定 release 签名（1.0.2 起统一，可覆盖升级）             |
| 版本号       | `1.0.5`（versionCode `6`）                                |
| Release 页   | GitHub → Releases → `v1.0.5-android.<构建号>`             |

### 1.2 安装步骤

```bash
# 手机已开启「开发者选项 → USB 调试」，并允许本机调试
adb devices
adb install -r soundisle-android.apk
```

也可以把 APK 传到手机，用文件管理器点击安装；系统提示时允许「安装未知应用」。

- 从 `v1.0.1` 或更早版本升级：签名已更换，需要**卸载旧版再安装 1.0.2**（会清空 App 内数据）。
- 从 `v1.0.2` 起：后续版本可直接覆盖安装，登录状态、歌单、收藏会保留。
- 若提示「签名不一致 / 应用未安装」：先卸载旧版再装。**卸载会清空 App 内歌单、收藏、Cookie 和下载记录**，已导出到 `Music/声屿` 的文件不会被删除。
- 重装后本地库为空时，进入「音乐库 → 本地」点右上角导入按钮，或空状态里的「从 Music/声屿 导入」，即可把系统目录里的歌曲复制回 App（首次需授予「音乐和音频」权限）。
- 若 Play Protect 拦截：选择「仍要安装」。这是 debug 签名导致的正常提示。

### 1.3 确认装的是新版

任选一种：

1. 手机「设置 → 应用 → 声屿 → 应用信息」查看版本号，应为 **1.0.5**。
2. 电脑执行：

```bash
adb shell dumpsys package app.soundisle.music | grep -i version
```

3. 对照 GitHub Release 页的 tag 与安装包下载时间。

> 「设置 → 关于」现在直接读取安装包版本与核心版本，应与系统「应用信息」一致。

### 1.4 首次启动权限

| 系统版本    | 会申请的权限                | 用途                     |
| ----------- | --------------------------- | ------------------------ |
| Android 13+ | 通知（POST_NOTIFICATIONS）  | 媒体通知、锁屏播放控制   |
| Android 9-  | 存储（WRITE_EXTERNAL_STORAGE） | 下载导出到公共音乐目录 |

- 通知权限建议允许；拒绝后仍能播放，但通知栏/锁屏不显示控制。
- 权限拒绝后可在「设置 → 应用 → 声屿 → 权限」重新打开。

## 2. 测试环境准备

| 项目     | 建议                                                         |
| -------- | ------------------------------------------------------------ |
| 网络     | Wi-Fi 与移动网络各测一次；弱网可用「飞行模式切换」模拟       |
| 存储     | 至少留 1 GB 空间；下载 FLAC 更占空间                         |
| 电量优化 | 若后台播放被杀，把声屿设为「不受限制 / 允许后台活动」        |
| 账号     | 需要会员歌曲时，先在设置里扫码登录网易云 / QQ 音乐           |
| 清空数据 | 设置 → 应用 → 声屿 → 存储 → 清除数据（用于复现首次启动问题） |

> 「清除数据」会删除 App 私有目录中的歌单、收藏、Cookie、下载文件与下载记录，但**不会删除**已导出到 `Music/声屿` 的副本。

## 6. 排障决策树

### 6.1 卡在「正在启动音乐核心…」或「音乐核心启动失败」

1. 等 15 秒；首次启动 + 低端机可能较慢。
2. 杀掉 App 重开一次。
3. 仍失败：看错误页完整文本并截图。
4. 检查手机剩余存储是否充足（至少几百 MB）。
5. 检查是否安装了 x86_64 模拟器版本（本包不支持模拟器）。
6. 收集日志（第 7 节），重点看 `core_error`、`GoLog`、`AndroidRuntime`。
7. 若是覆盖安装后出现：卸载重装再试（会丢 App 内数据）。

### 6.2 首页/搜索/榜单一直「加载失败」

1. 确认手机能正常上网（浏览器打开任意网页）。
2. 换 Wi-Fi / 移动网络再点「重试」。
3. 设置 → 默认搜索源，先只留「网易云音乐」再试；某个平台被上游限制不影响其他平台。
4. 若只有某个音源失败，属于上游接口问题，记录音源名与错误文本即可。
5. 所有音源都失败：收集日志，记录发生时间与网络类型。

### 6.3 点歌后不播放 / 一直转圈

按顺序判断：

1. **一直 loading**：等 10~30 秒（换源会串行搜索多个平台）。
2. **提示试听片段**：能播但只有片段，属于会员/版权限制。
3. **提示「已自动切换到 XX」**：换源成功，正常。
4. **提示「…已尝试其他音源，仍未找到可播放版本」**：该歌曲在所有候选源都不可用。
5. **提示「平台没有返回播放地址」/「该平台不支持在线播放」**：该音源接口限制。
6. **有进度但无声**：检查手机媒体音量、蓝牙输出、勿扰模式；换一首歌对比。
7. **只有某几首失败**：记录歌名、歌手、来源平台，属于上游版权概率大。

> 判断是否为客户端问题：同一首歌换一个音源能播，基本是上游版权/接口问题，不是播放器 bug。

### 6.4 下载失败 / 找不到文件

1. 音乐库 → 下载，看任务状态与错误文本；完成状态应包含「歌词 / 封面」。
2. 若状态只有「已完成」：本曲音源没有可获取的歌词或封面；换一个音源再下载。
3. 打开 `Music/声屿`，确认音频旁是否有 `.lrc` 与 `.cover.*`；没有则把歌曲名、音源记下来。
4. 本地播放没有歌词但目录里有 `.lrc`：退出播放页重进，或在「本地」下拉重新扫描。
2. 若「下载失败：…」：记录原因；换一首歌或换音源再试。
3. 若「已完成」但没有「已保存到…」：
   - 等 2~5 秒（导出在后台线程进行，轮询间隔 2 秒）。
   - Android 9- 检查存储权限是否授予。
   - 查看是否显示「保存到系统音乐库失败：…」。
4. 用文件管理器进入 `内部存储/Music/声屿`；部分机型文件管理器需要手动刷新或重新扫描媒体库。
5. 用其他音乐 App 的「扫描本地音乐」确认文件是否被媒体库收录。
6. 仍找不到：记录歌曲名、下载完成时间、错误文本，收集日志中 `MediaStore`、`exportAudio` 相关行。

### 6.5 通知栏 / 锁屏没有播放控制

1. Android 13+：设置 → 应用 → 声屿 → 权限 → 通知，确认已允许。
2. 播放一首歌后等 2~3 秒再看通知栏。
3. 检查是否处于「勿扰模式」或通知被折叠。
4. 部分系统需要在「通知管理」里允许「媒体播放」类别。
5. 1.0.3 起暂停后通知会保留；若仍看不到，进入「设置 → 关于 → 播放通知」查看权限、渠道状态与在途通知数，点右侧刷新。

### 6.6 点歌后进不了播放页 / 底部没有控制条

1. 先确认歌曲是否真的开始播放（是否有声音、播放页能否从迷你播放器进入）。
2. 首页与音乐库底部应出现迷你播放器；点它进入播放页。
3. 歌单/收藏/排行榜等二级页面在 v2 中也应显示迷你播放器。
4. 若仍没有：截图当前页面，记录从哪个入口进入、点了哪首歌。
5. 若是「点了歌曲但什么都没发生」：按 6.3 判断是否播放失败；失败时会有错误提示。

### 6.7 歌曲「⋯」菜单点不到底部项

1. v2 已改为可滚动菜单，向上滑动即可看到「下载到本地」等底部项。
2. 若菜单仍然无法滑动：记录机型、系统版本、屏幕分辨率/字体大小，截图菜单。
3. 系统字体调大可能导致内容更高，可临时调回默认字号对比。

### 6.8 扫码登录失败

1. 二维码是否有有效期提示（约 3~5 分钟）；过期点「刷新二维码」。
2. 手机端 App 是否确认登录；确认后等待 2~3 秒。
3. 提示「平台没有返回登录会话」：改用「手动填写 Cookie」。
4. Cookie 获取：浏览器登录对应平台 → 开发者工具 → Network → 任意请求 → 复制 Cookie 请求头。
5. 保存后重启 App，确认设置页显示「已登录」。

脚本会在当前目录生成 `soundisle-diag-<时间>/`，包含：系统信息、App 版本、日志、崩溃日志、媒体会话、通知、`Music/声屿` 文件列表和当前截图。反馈时直接打包该目录。

### 7.3 手动采集命令

```bash
# 1) 清空旧日志
adb logcat -c

# 2) 在手机上复现问题（例如点歌播放失败）

# 3) 导出完整日志
adb logcat -d -v threadtime > soundisle-log.txt

# 4) 只看关键行
adb logcat -d -v threadtime | grep -iE \
  "flutter|soundisle|goLog|just_audio|audio_service|AndroidRuntime|MediaStore|exportAudio" \
  > soundisle-key.log
```

补充证据：

```bash
# 安装包版本与路径
adb shell dumpsys package app.soundisle.music | grep -iE "version|codePath"

# 进程是否存活
adb shell pidof app.soundisle.music

# 崩溃缓冲区
adb logcat -d -b crash > soundisle-crash.txt

# 媒体会话（通知/锁屏控制）
adb shell dumpsys media_session > soundisle-media-session.txt

# 已导出的音乐文件
adb shell "ls -l '/sdcard/Music/声屿'" > soundisle-music-files.txt

# 系统与机型
adb shell getprop > soundisle-props.txt
```

> 若 `adb` 提示 `device unauthorized`：在手机上点「允许 USB 调试」；`no devices`：换数据线/USB 模式为「文件传输」。

### 7.4 App 内可直接看到的信息

设置 → 关于：

- 「本地音乐核心」：`http://127.0.0.1:<端口>`，说明核心已启动。
- 「数据目录」：App 私有数据路径，下载文件与 `state.json` 所在位置。

截图这两项有助于判断是「核心没起来」还是「网络/上游失败」。

## 9. 已知限制（不是缺陷）

1. **仅支持 arm64 真机**：APK 只含 arm64-v8a，不支持 32 位设备与 x86_64 模拟器。
2. **稳定签名**：1.0.2 起所有包使用同一 release keystore，可覆盖升级；首次从旧版迁移需卸载。
3. **会员/版权歌曲**：部分歌曲只能试听或完全不可播；换源仍失败时属上游限制。
4. **部分音源需要登录**：网易云、QQ、酷狗、汽水等会员/高音质能力依赖 Cookie。
5. **汽水音乐**：会员整曲需要 Cookie 与本机签名器，未配置时可能只返回试听。
6. **Apple Music / Spotify**：未配置凭据时匿名接口通常只提供试听片段。
7. **千千音乐**：歌单搜索可能为空，属上游接口限制。
8. **下载依赖 App 进程存活**：强制结束 App 会中断下载；重启后记录保留并标记为中断，点任务右侧刷新按钮可重试。
9. **断点续传取决于音源**：服务器支持 `Range` 时重试会从断点继续，否则自动从头下载；临时文件以 `.part` 结尾，不会出现在本地音乐里。
10. **App 内删除本地歌曲**：只删 App 私有副本，不一定会删 `Music/声屿` 中已导出的副本。
11. **通知权限/渠道被系统关闭**：可在「设置 → 关于 → 播放通知」查看状态并跳转系统设置。
12. **固定深色主题**：浅色主题尚未接入，设置中的开关为占位。
13. **「关于」页版本文案可能滞后**：以系统应用信息/Release tag 为准。
14. **歌词缺失**：部分歌曲上游无歌词，播放页显示「暂无歌词」，不是播放失败。
